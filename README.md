# Focus Flow

Turn a noisy to-do list into one small, satisfying next step.

This repository includes a simple starter app, source files, and a release bundle for download.

## Files
- `index.html`
- `styles.css`
- `app.js`

## Run locally
Open `index.html` in a browser or use a simple static server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000
